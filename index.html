设置

Provider 边界、自部署 API 与三端路线

自部署 API（网易云 / QQ 音乐）

浏览器直连自部署 API 会有跨域限制。请在本地或自有服务器部署 NeteaseCloudMusicApiEnhanced 与 L-1124/QQMusicApi， 填入访问地址（如 http://localhost:3000）。前端只调用搜索和歌词接口；授权、Cookie 和账号态请放在你自己的服务端处理。

数据与播放

队列、播放位置、音量、主题会在本地浏览器保存，刷新后恢复。清除本地数据会移除所有本地导入曲目与配置。

三端路线

当前为 HTML 概念稿。终极目标是用 Capacitor 打包 iOS / Android、用 Tauri 或 Electron 打包 Windows， 复用同一套 provider / lyrics / storage / player 模块。本地文件在三端分别走各平台原生文件 API。
